Introduction

NotLFS (Not Linux From Scratch) is a framework for building custom Linux systems from source code. It provides the tools, package definitions, and build system to create your own distribution.

Unlike traditional distributions, NotLFS doesn't provide pre-built binaries. Instead, you compile everything from source, giving you complete control over your system.

Philosophy: NotLFS follows the KISS principle (Keep It Simple, Stupid). The framework is designed to be as simple as possible while still providing powerful features.

Requirements

To build a system with NotLFS, you need:

  • A Linux system (any modern distribution, i recommend the Gentoo Install USB as you can --oneshot install to the install medium to add dependencies to get notlfs up and running)
  • At least 20 GB of free disk space
  • At least 4 GB of RAM (8 GB recommended for desktop profile)
  • Basic development tools (gcc, make, bash, etc.)
  • Internet connection (to download source packages)

Recommended host system packages:

# Debian/Ubuntu
$ sudo apt-get install build-essential git wget curl bison flex texinfo

# Fedora/RHEL
$ sudo dnf install gcc gcc-c++ make git wget curl bison flex texinfo

# Arch Linux
$ sudo pacman -S base-devel git wget curl bison flex texinfo

# Gentoo Linux (install medium of the desktop variety is recommended LiveGUI USB Image Gentoo (amd64)) - Should Be installed on the install medium, but just in case look at it, 
$ sudo emerge --oneshot --ask sys-devel/gcc sys-devel/make sys-devel/bison sys-devel/flex sys-devel/texinfo net-misc/wget net-misc/curl

Installation

Installing NotLFS is simple:

# Clone the repository
$ git clone https://github.com/Bitraxis/notlfs.git
$ cd notlfs

# Initialize the build environment
$ ./notlfs.sh init

# Build your system
$ ./notlfs.sh -p base

This will create a complete build environment in the notlfs directory.

Quick Start

After installation, you can build different profiles:

Command Description
./notlfs.sh -p minimal Build a minimal system (~300-500 MB)
./notlfs.sh -p base Build a base system with dev tools (~1.5-2.5 GB)
./notlfs.sh -p desktop Build a desktop system with KDE Plasma (~8-15 GB)
./notlfs.sh -p server Build a server system (~2-4 GB)

Build Profiles

NotLFS comes with four pre-defined build profiles:

Minimal

Absolute minimal system with only essential packages. Perfect for embedded systems, containers, or as a foundation for custom builds.

Base

Complete system with development tools, networking, and essential utilities. Suitable for general-purpose use as a server or development workstation.

Desktop

Full desktop environment with KDE Plasma, graphical applications, and multimedia support. For desktop workstations and GUI machines.

Server

Server-oriented system with web server, database, and file services. For production servers and cloud instances.

Configuration

NotLFS uses XML configuration files. The main configuration file is configs/notlfs.xml.

Example configuration:

<?xml version="1.0" encoding="UTF-8"?>
<notlfs>
    <system>
        <name>MyLinux</name>
        <architecture>x86_64</architecture>
        <hostname>mylinux</hostname>
    </system>
    <build>
        <profile>base</profile>
        <init_system>s6-rc</init_system>
        <mode>interactive</mode>
    </build>
</notlfs>

Package Management

NotLFS supports multiple package managers that can be added post-install:

  • xbps - Void Linux's lightweight package manager
  • nix - Declarative, reproducible package management
  • opkg - Lightweight package manager for embedded systems
  • apk - Alpine Linux's simple package manager
  • custom - NotLFS-native package manager

To add a package manager after installation:

# From within your NotLFS system
$ /usr/local/notlfs/bin/pkg-manager.sh install xbps

Init Systems

NotLFS supports 8 different init systems:

Init System Description Complexity
s6 Minimalist supervision suite Low
s6-rc s6 with dependency-based service management Medium
dinit Fast, dependency-based init Low
runit Simple, reliable service supervisor Low
sysv Traditional SysV init Low
systemd Full-featured system and service manager High
openrc OpenRC init system (Gentoo-style) Medium
s6-init s6 as PID 1 Low

To specify an init system:

$ ./notlfs.sh -p base -i s6-rc

Customization

NotLFS is designed to be fully customizable. You can:

  • Create custom profiles: Define your own package sets and configurations
  • Add packages: Add new package definitions to the packages/ directory
  • Modify builds: Customize build options and optimization flags
  • Change branding: Use the distro-namer tool to customize your distribution name and branding
  • Add hooks: Add custom build hooks at various stages of the build process

Troubleshooting

If you encounter issues:

  • Check logs: Build logs are stored in the logs/ directory
  • Validate configuration: Run ./notlfs.sh validate to check your configuration
  • Check dependencies: Ensure all required build dependencies are installed on your host system
  • Ask for help: Visit the community page for support
Common Issues:
  • Missing packages: Ensure all package sources are downloadable
  • Build failures: Check the log files for specific error messages
  • Permission issues: Some build steps require root privileges
  • Disk space: Ensure you have enough free space for the build
