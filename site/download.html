Download NotLFS

NotLFS is a framework, not a pre-built distribution. You build your own system from source using the NotLFS tools. However, you can download the NotLFS framework itself to get started.

Latest Release

NotLFS 1.0.0

Version: 1.0.0

Released: June 4, 2026

The first stable release of NotLFS with support for multiple init systems and build profiles.

Download NotLFS 1.0.0 (zip) Download NotLFS 1.0.0 (tar.gz)

Release Notes

  • Added four build profiles: minimal, base, desktop, server
  • Support for 8 init systems: s6, s6-rc, s6-init, dinit, runit, sysv, systemd, openrc
  • Package manager adder tool for post-install package management
  • Distro name changer for custom branding
  • Improved documentation and build process
