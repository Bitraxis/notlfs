Welcome to NotLFS

NotLFS (Not Linux From Scratch) is a modular framework for building custom Linux systems from source code. Inspired by the classic Linux From Scratch project, NotLFS adds modern features like multi-init system support, build profiles, and extensible package management.

Note: NotLFS is a framework, not a distribution. You build your own custom Linux system using the NotLFS tools and package definitions.

Features

  • Multi-Init System Support: s6, s6-rc, dinit, runit, sysv, systemd, openrc
  • Modular Design: Build only what you need with customizable profiles
  • Extensible: Add your own packages and configurations
  • Build Modes: Auto (unattended), Interactive, Manual (step-by-step)
  • Package Management: Add package managers post-install (xbps, nix, opkg, apk, custom)
  • Smart Features: Dependency resolution, parallel builds, validation
  • Custom Branding: Name your distribution whatever you want

Quick Start

Get started with NotLFS in just a few commands:

# Clone the NotLFS repository
$ git clone https://github.com/Bitraxis/notlfs.git
$ cd notlfs

# Build a minimal system
$ ./notlfs.sh -p minimal

# Build with a specific init system
$ ./notlfs.sh -p base -i s6-rc

# Build a desktop system
$ ./notlfs.sh -p desktop -i systemd

See the documentation for detailed instructions.
