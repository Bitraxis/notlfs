NotLFS Build Profiles

NotLFS comes with four pre-defined build profiles, each tailored for different use cases. You can also create your own custom profiles.

Profile Details

Minimal Profile

Use Case: Embedded systems, containers, rescue systems, custom builds with maximum control

Features: Smallest possible NotLFS installation, fast build time, minimal disk footprint, security hardening enabled by default

Packages: Core system, init system, essential utilities only

Command: ./notlfs.sh -p minimal

Base Profile

Use Case: Development workstations, general-purpose servers, base for custom distributions

Features: Complete Linux system, full development toolchain, networking support, version control systems, system monitoring tools

Packages: All minimal packages + dev tools, networking, languages (Python, Perl, Ruby)

Command: ./notlfs.sh -p base

Desktop Profile

Use Case: Desktop workstations, development machines with GUI, general-purpose desktop computers

Features: Full KDE Plasma desktop, graphics stack (X11/Wayland), audio (PulseAudio/ALSA), video playback, Firefox browser, network management, Bluetooth

Packages: All base packages + KDE Plasma, graphics, multimedia, productivity apps

Command: ./notlfs.sh -p desktop -i systemd

Note: systemd is recommended for the best desktop experience, though s6-rc is the default.

Server Profile

Use Case: Web servers, database servers, file servers, mail servers, cloud instances, production servers

Features: Nginx web server, PostgreSQL database, Samba/NFS file servers, Postfix mail server, dnsmasq DNS, fail2ban security, iptables firewall, chrony time sync, cron

Packages: All base packages + web server, database, file server, mail server, security tools

Command: ./notlfs.sh -p server -i runit

Custom Profiles

You can create your own custom profiles by combining existing profiles or defining your own package sets.

Creating a Custom Profile

Create a new directory in the profiles/ directory with a profile.xml file:

<?xml version="1.0" encoding="UTF-8"?>
<profile name="my-profile">
    <description>My custom NotLFS profile</description>
    <init_system>s6-rc</init_system>
    <packages>
        <include profile="base" />
        <package name="nginx" enabled="true" />
        <package name="postgresql" enabled="true" />
    </packages>
    <features>
        <feature name="server">true</feature>
    </features>
</profile>

Using a Custom Profile

Use your custom profile with the -p option:

$ ./notlfs.sh -p my-profile
